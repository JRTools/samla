Worker-Token lokal erzeugen

Diese Datei als HTML herunterladen und im eigenen Browser öffnen. Die Erzeugung läuft lokal mit Web Crypto. Es werden keine Daten übertragen und keine Samla-Einstellungen verändert. Die Datei gehört außerhalb des öffentlichen Webverzeichnisses.

Das Token sicher im Passwortmanager beziehungsweise Scheduler verwahren. In Samlas .env nur den Hash eintragen. Das Token nie in eine URL, einen Screenshot oder ein öffentliches Repository kopieren. Ein neues Token ersetzt das alte erst nach Änderung der Konfiguration.
