# Prüfung Iteration 38: gemeinsame Tagänderungen

Alle vier isolierten lokalen Kombinationen PHP 8.4.5/8.5.4 und MySQL 8.0/MariaDB 11.8 erfolgreich: jeweils 213 Unit-/Architekturtests mit 1254 Assertions und 321 Integrationstests mit 1666 Assertions (534 Tests/2920 Assertions je Kombination). Syntax aller 278 eigenen PHP-Dateien erfolgreich. Keine neue Migration; vorhandenes Schema ist aktuell.

Ein neuer Unitfall prüft unveränderliche verschachtelte Auswahlwerte, Operations-/Bereichs-/Signaturbindung und ungültige Batchformen. Vier weitere Integrationsfälle prüfen gemeinsame Add-/Remove-Änderungen an zwei Dateien, erhaltene Beschreibungen und andere Tags, unveränderte Zuweisungen ohne Revisionssprung/Einzelereignis, individuelle Audits/Outboxereignisse nur für tatsächliche Änderungen, veraltetes Mitglied und volle Tagkapazität ohne Teiländerung, Pluginveto des exakten Plans sowie einen injizierten SQL-Fehler mit vollständigem Rollback. Die Webformulare prüfen Auswahl, Namen, CSRF, Bestätigung und wiederholtes veraltetes Absenden.

Vollständiger synthetischer HTTP-/HTTPS-Durchlauf erfolgreich: PHP 8.4/8.5 Entwicklungs-HTTP und PHP 8.4 Produktions-HTTPS.
